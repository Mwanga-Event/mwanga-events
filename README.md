# Mwanga Events — Brand Website Demo

Premium single-page website demo for **Mwanga Events**, a LED visual & full event
production company launching in Kampala, Uganda. Built to pitch the brand: live
generative brand marks, editorial typography, and a WhatsApp-first inquiry flow.

## Stack
Vite · Tailwind CSS v4 · GSAP (ScrollTrigger / SplitText) · Lenis

## Run
```bash
cd site
npm install
npm run dev      # dev server
npm run build    # production build → site/dist
```

## Structure
- `site/` — the website (source in `site/src`, images in `site/public/img`)
- `DESIGN-SYSTEM.md` — design system + photography direction
- `Mwanga Events logo design.pdf` — brand identity study (source of the five marks)
- `source-images/` — original AI concept visuals
